# Privacy, Security, and Responsible Research

Medical information systems are safety-sensitive. This project therefore draws a clear line between public research communication and private software development.

## Public repository boundaries

This repository is intended to contain only non-confidential research descriptions, high-level plans, and carefully reviewed technical notes. It must not contain:

- identifiable patient, employee, or laboratory customer information;
- credentials, access tokens, private keys, environment files, or private endpoints;
- internal database exports, security-sensitive infrastructure details, or confidential contracts;
- proprietary source code, unless a separate release decision explicitly authorizes publication.

## Data and evaluation

Research examples and software tests should use synthetic data. Any future use of real clinical records would require an appropriate legal basis, organizational authorization, minimization, security controls, and applicable ethical or regulatory review. No such use is implied by this public project description.

## AI-assisted development

AI tools may assist with public literature review, code navigation, documentation, and test design. Outputs require human verification. Sensitive records or secrets must not be submitted to external AI services without a separate approved data-governance process. AI-generated suggestions are not clinical judgments or validated evidence.

## Medical and regulatory boundaries

The project is not a medical device offered for clinical use through this repository, and its presence on GitHub does not imply fitness for diagnosis or treatment. Compliance, conformity, accreditation, and operational readiness require their own structured assessments and documented evidence.

## Disclosure and reuse

A public research description is not a license for the private implementation. Do not copy private material from elsewhere into this repository. Any future open-source release should receive explicit ownership, third-party license, privacy, and security review before publication.
